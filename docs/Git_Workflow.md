# GitVerse: ветка, задачи и PR

Локальный репозиторий ПР4 готовится отдельно от ПР1–ПР3. Ветка: feature/prediction,
базовая ветка main содержит начальные настройки. Remote кафедры не предоставлен;
issues и PR ниже — подготовленный текст, не опубликованные сущности.
Независимое ревью не выполнялось. Merge не выполнен.

Если в кафедральном репозитории уже есть main, перенести проект в новую ветку
**от актуальной origin/main**, сохранив требуемые преподавателем пути. Не заменять
историю общего репозитория локальной историей и не применять force push.

## Задачи для публикации

| Название | Критерий приёмки | Статус |
|---|---|---|
| Двухпользовательский Third Person прототип | UE собирает проект, хост/клиент видят друг друга | Исходники готовы, запуск не проверен |
| Спринт в SavedMoves | Custom_0, сохранение/replay, серверные ограничения | Реализовано, сборка не проверена |
| Baseline и режим CSP | F2, ожидание RPC в OFF, мгновенный ввод в ON | Реализовано, запуск не проверен |
| Серверный отказ и коррекция | F3, запрет, реальная CMC correction и replay | Код готов, T5 не выполнен |
| Сетевой эксперимент | T1–T5, профили 100/175±25 мс, видео, логи | Инструменты готовы, испытания не выполнены |
| Документы и защита | Два обязательных MD, инструкция и ответы | Подготовлены; результаты дописать после запуска |

## Подготовленное описание Pull Request

**Заголовок:** feat: server-authoritative sprint prediction with CMC saved moves

**Из:** feature/prediction. **В:** main. До реального запуска PR следует держать Draft.

Добавлен многопользовательский C++ прототип PredictionLab с камерой от третьего лица.
Спринт 450 → 900 см/с передаётся флагом Custom_0 в сохранённых ходах CMC.
Сервер самостоятельно ограничивает скорость и проверяет режим движения и свой запрет.
F2 сравнивает локальное предсказание с ожиданием RPC-ответа, F3 создаёт учебное расхождение.
Позицию исправляет CMC с повторным проигрыванием сохранённых ходов.

Включены генератор арены, скрипты сборки/двух окон/сетевых профилей,
анализ реальных логов, документация, матрица T1–T5 и сценарий очной защиты.

**Проверка:** перечислить фактические локальные проверки из Verification.md.
Сборка UE, T1–T5 и видео пока не выполнены; не помечать PR готовым к сдаче до их выполнения.

**Ограничения:** геометрический Third Person вместо бинарных ассетов шаблона;
F3 — учебный RPC; нет matchmaking и нагрузочных испытаний.
